# 캡컷 조립 가이드 (9:16, 1080x1920)

## 폴더 구성
- `00_opening_clip.mp4` : Flow 할아버지 오프닝 클립 (10초, 음성 포함)
- `slides/` : 슬라이드 6장 (자막 없는 상태). 순서대로 번호가 붙어 있음
- `audio/bgm_ambient.wav` : 잔잔한 배경음 (볼륨 7% 권장)
- `script.txt` : 슬라이드별 대사(자막용 텍스트)
- Flow에서 만든 `g1`~`g8` 클립은 `../flow_assets/`에 올리기

## 순서 (타임라인)
| 구간 | 영상 트랙 | 음성 |
|---|---|---|
| 0~10초 | `00_opening_clip.mp4` (오른쪽 아래 Flow 로고는 크롭 12%로 가리기) | 클립 음성 |
| 이후 | `01_agenda` → `02_samhap` → `03_tasks_ink` → `04_calendar` → `05_cards` → `06_outro_ink` | `g1`→`g8` 음성 (g1: 01, g2·g3 앞: 02, g3 뒤·g4: 03, g5·g6 앞: 04, g6 뒤·g7 앞: 05, g7 뒤·g8: 06) |

## 캡컷 작업
1. 새 프로젝트 → 비율 **9:16**
2. 오프닝 클립 배치 후 **크롭**으로 오른쪽·아래 12% 잘라내고 화면 가득 채움
3. 슬라이드 이미지를 순서대로 놓고 길이를 `g` 클립 음성 길이에 맞춤
4. `g1`~`g8` 클립은 영상 트랙을 숨기거나 "오디오 분리"로 음성만 사용
5. 자막: **자동 캡션**을 쓰면 음성에서 바로 생성됨. 틀린 글자는 `script.txt`로 교정
6. 효과: 슬라이드에 "줌인" 애니메이션(100→104%), 전환은 "디졸브" 0.3초
7. `bgm_ambient.wav`를 오디오 트랙에 놓고 볼륨 7%
8. 내보내기: 1080p, 30fps
