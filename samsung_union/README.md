# (가칭) 삼성전자 [ ○○ ] 노동조합 · 설립 패키지

> **삼성전자 소속 근로자만** 가입하는 기업별 노동조합(복수노조) 설립용 자료입니다. 운전직군이 주도하되 삼성전자의 모든 직군을 대상으로 합니다.
> 근거 법령: 「노동조합 및 노동관계조정법」(이하 노조법). 조문·기간은 작성 시점 기준이므로 제출 전 최신 법령과 관할 고용노동관서에 반드시 확인하고, 가능하면 공인노무사 검토를 받으세요.

## 1. 설계 요약

| 항목 | 결정 |
|---|---|
| 노조 형태 | **기업별 노조** (삼성전자 단일 회사) |
| 핵심 대상 | 사업부 분류상 **"기타" 소속 직원 약 1만 1,600명** (기존 노조 가입률 16.5%, 미가입 약 9,700명) → `05_target_analysis.md` |
| 가입 대상 | 삼성전자(주)와 근로계약을 맺은 근로자 (전 직군·직급, 정규직·계약직 포함) |
| 가입 제외 | 임원, 인사·노무 결정권자 등 사용자 이익대표자 / 계열사·협력사·파견 근로자 |
| 복수노조 | 삼성전자 내 기존 노조와 **별개로 설립** (설립 자체는 자유) |
| 조직 구조 | 본조 → **사업장별 지부**(수원·기흥·화성·평택·온양·천안·구미·광주·서울 등) → **직군별 분회**(운전직 분회 등) |
| 신고처 | 삼성전자 사업장이 2개 이상 시·도에 걸쳐 있으므로 **고용노동부장관** (주된 사무소 관할 지방고용노동관서에 접수) |

## 2. ⚠ 가장 먼저 확인할 것: "내가 삼성전자 소속인가"
- 근로계약서·급여명세서의 회사명이 **삼성전자(주)** 여야 합니다.
- 운전직은 삼성전자 직고용이 아니라 협력·용역·파견업체 소속인 경우가 있습니다. 그렇다면 이 노조의 가입 대상이 아니며 설립 주도도 불가능하므로, 설계를 다시 해야 합니다.
- "임직원"이라고 하셨지만 **임원은 가입할 수 없습니다.** 가입시키면 노조로 인정되지 않을 수 있습니다(노조법 제2조 제4호 가목). 규약상 "삼성전자 직원(근로자)"으로 한정했습니다.

## 5. 복수노조로서의 현실과 전략
- **설립은 자유**지만, 교섭은 회사 안의 노조들이 **창구를 하나로 단일화**해야 합니다. 과반수 노조가 있으면 그 노조가 교섭대표가 됩니다.
- 신생 소수노조가 할 수 있는 것:
  1. 교섭 요구 공고 기간에 **반드시 교섭 요구** → 교섭 참여 노조 지위 확보
  2. 교섭대표노조의 **공정대표의무** 위반(소수노조·운전직 차별) 시 노동위원회 시정 신청
  3. 운전직 근로조건이 다른 직군과 현저히 다르면 노동위원회에 **교섭단위 분리** 신청 검토
  4. 조합원 확대로 장기적으로 교섭력 확보, 또는 공동교섭대표단 참여(전체 조합원의 10% 이상 노조)
- **근로시간면제(전임자)** 한도는 교섭대표노조와의 관계·단체협약으로 정해지는 경우가 많아, 초기에는 무급·근무시간 외 활동을 전제로 계획하세요.

## 6. 하지 말아야 할 것
- ❌ 회사 메일·메신저·인트라넷·업무 차량 장비로 노조 활동 (개인 휴대폰·개인 메일 사용)
- ❌ 운전 업무 중 알게 된 임원 대화·일정·회사 기밀 이용
- ❌ 근무시간 중 조직 활동 (단체협약·회사 허락이 없는 한)
- ❌ 조합원 명단 유출
