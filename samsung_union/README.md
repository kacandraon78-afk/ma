# (가칭) 삼성 통합 노동조합 · 설립 패키지

> 운전직군을 포함해 **삼성 계열사·직군·고용형태를 가리지 않고** 가입할 수 있는 초기업 단위 노동조합 설립용 자료입니다.
> 근거 법령: 「노동조합 및 노동관계조정법」(이하 노조법). 조문·기간은 작성 시점 기준이므로 제출 전 최신 법령과 관할 고용노동관서에 반드시 확인하고, 가능하면 공인노무사 검토를 받으세요.

## 1. 왜 "초기업 노조"인가

| 형태 | 가입 범위 | "모두 아우르기" |
|---|---|---|
| 기업별 노조 (예: 삼성전자 노조) | 해당 회사 근로자만 | ✗ 계열사·협력사 직원 가입 불가 |
| **초기업 노조 (본 패키지)** | 여러 회사의 근로자 | ✓ 삼성전자·계열사·협력/도급/파견 근로자 모두 가입 가능 |

- 운전직은 회사 소속이 제각각인 경우가 많습니다(삼성전자 직고용 / 계열사 / 협력·용역업체 / 파견). 초기업 노조여야 소속이 달라도 한 노조로 묶을 수 있습니다.
- 조직 구조: **본조 → 지부(회사별) → 분회(직군·사업장별, 예: 운전직 분회)**.
- 교섭은 회사(사용자)별로 진행됩니다. 각 지부가 해당 회사와 교섭하며, 회사별로 교섭창구 단일화 절차가 적용됩니다.

## 4. 운전직군이 특히 알아둘 점

1. **내 사용자가 누구인지 확인**: 근로계약서·급여명세서상의 회사가 교섭 상대입니다. 삼성전자 직고용인지, 협력·용역·파견업체 소속인지 먼저 확인하세요.
2. **원청 교섭 가능성**: 노조법 제2·3조 개정(이른바 '노란봉투법', 2025년 개정·2026년 시행으로 알려짐)으로, 근로조건을 실질적·구체적으로 지배·결정하는 원청도 사용자로 볼 수 있게 되었습니다. 협력사 소속 운전직이라면 삼성 원청에 교섭을 요구할 근거가 될 수 있습니다. **시행일·세부 기준은 반드시 최신 확인 필요.**
3. **가입 제외 대상**: 임원, 인사·노무 결정권이 있는 관리자 등 "사용자 또는 그 이익을 대표하는 자"가 가입하면 노조로 인정되지 않을 수 있습니다(노조법 제2조 제4호 가목). 규약에 제외 조항을 넣어 두었습니다.
4. **업무 특성상 주의**: 임원 차량 운전 등에서 알게 된 대화·일정·회사 정보는 노조 활동에 절대 사용하지 마세요(비밀유지 의무 위반 및 징계 사유).
